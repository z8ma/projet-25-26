# Creative Match Platform

Plateforme de mise en relation entre créateurs de contenu et professionnels créatifs (graphistes, designers 3D, motion designers, etc.) avec une IA au cœur du système.

## 🎯 Concept Principal

Une plateforme par abonnement qui utilise l'intelligence artificielle pour:
1. Aider les créateurs à brainstormer et affiner leurs projets
2. Clarifier leurs vrais besoins
3. Anticiper les questions des investisseurs et partenaires
4. Générer des documents professionnels (pitch decks, briefs créatifs, etc.)
5. Matcher intelligemment avec les professionnels adaptés

## 🏗️ Architecture Technique

- **Frontend:** React + TypeScript
- **Backend:** Node.js + Express
- **Base de données:** PostgreSQL
- **IA:** Double API (GPT-4 + Claude) pour performances optimales
- **Hébergement:** Hostinger
